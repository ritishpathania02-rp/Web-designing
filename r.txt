To create virtual environment
============================================================================
powershell -->

1.Create
    python -m venv .venv
2.Activate
    .venv\Scripts\Activate.ps1
    (
        if:  running scripts is disabled
        use: Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
    )
3. deactivate

============================================================================
command prompt -->
1.Create
    python -m venv .venv
2.Activate
    .venv\Scripts\activate.bat
3.deactivate
